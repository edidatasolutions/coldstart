# Changelog

## coldstart 0.1.0

- Initial release.
- Difficulty prediction from item features with honest
  seen/unseen-family uncertainty
  ([`cs_predictor()`](https://edidatasolutions.github.io/coldstart/reference/cs_predictor.md)).
- Grid-Bayes calibration with robust Student-t predicted priors
  ([`cs_calibrate()`](https://edidatasolutions.github.io/coldstart/reference/cs_calibrate.md)).
- Pretest sample-size planning
  ([`cs_plan()`](https://edidatasolutions.github.io/coldstart/reference/cs_plan.md)).
- Family-level trust diagnostics and prior withdrawal
  ([`cs_check()`](https://edidatasolutions.github.io/coldstart/reference/cs_check.md),
  [`cs_distrust()`](https://edidatasolutions.github.io/coldstart/reference/cs_distrust.md)).
